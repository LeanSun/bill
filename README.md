# 轻账 · 收支看板

个人账单可视化面板。2024 — 2026 三年、1959 笔流水，全部跑在一个静态页里 —— 无构建、无依赖、无数据库。

打开 `index.html` 即可用。要跨设备共用一份账，附带一个零依赖的 Node 后端（`server/`），单进程同时发站点和 API。

线上：<https://leansun.github.io/bill/>

---

## 界面

两个视图，侧栏切换：**总览** 与 **日历**，**打开默认落在日历**（无 hash 时自动补 `#/calendar`）。旧的 `#/analysis`、`#/stats`、`#/trend` 深链仍可用，一律折到总览页。侧栏是三个同款全宽号按钮竖着排：蓝色「记一笔」，下面跟着**同宽同高的「深浅切换」和「配色」**（各 38px 高、图标 + 文字居中），底部再一行「云同步」；窄屏（≤940px）侧栏折成横条，这三颗按钮收成 36px 图标，云同步改由同排的云图标进入。

页面顶部不再有标题行：正文从 18px 留白起排，日历因此能多吃约 70px 的高度。侧栏宽 208px，右侧内容区按视口自适应铺满。

**总览** —— 顶部一条四格信息带（收入 / 支出 / 结余 / 储蓄率，各带同比、月均日均、笔数与 12 个月走势线），下面是七张图：月度收支趋势、支出构成、结余变化、**体重记录**（时间轴，带平均线和最新 / 区间 / 较首次变化）、消费日历热力、分类走势堆叠、高频项目 TOP 10。再往下是两张各自独立的整宽卡 —— **社保** 与 **报销费用**，不挤在同一张卡里，各管一件事，各自可单独拖拽、单独调宽高。切换视图时全部图一起重绘。

**配色自定义** —— 侧栏「配色」打开面板，五个支出分类 + 收入各一颗色块，HEX / RGB 双向同步。`palette()` 每次渲染都从 `:root` 的 `--cat-*` 读值，所以改一处，图表、筛选胶囊、格子里的条目、天页分类色一起跟着换。现在这套 —— 餐饮 `#FFC000`、日常 `#490033`、交通 `#264465`、服饰 `#8B5CF6`、娱乐 `#0000E4`、收入 `#E04A4A` —— 就是出厂默认，点「恢复默认」回到它。深色主题下亮度过低的自定义色会自动向白色混 48%，免得紫红在暗底上看成一块黑。切主题时会**连筛选区一起重排**（胶囊的 `--c / --ink` 是渲染时写死在内联样式里的，只重绘图表不会动它们），所以点一下深浅，那排「全部 / 餐饮 / 日常」的文字颜色当场就换，不用再点一次。

**社保** —— 总览倒数第二张整宽卡，标题就叫「社保」（原来那块「工资与五险一金」的牌子拆掉了），副标题改成一行实时摘要：`个人 ¥1,653.01 · 公司 ¥1,447.87 · 实发 ¥4,714.91`，左边四个字段改一格它就跟着重算。

| 字段 | 含义 | 默认 |
|---|---|---|
| 基数 | 社保 / 公积金缴费基数 | 8477 |
| 工资 | 税前工资 | 6400 |
| 绩效 / 补贴 | 参考项，只写在「实发」那行的脚注里 | 2425 / 550 |
| 差距 | 应发与实际到账的差（个税等杂项） | 32.075 |

五行缴费（养老金 8/0、公积金 7/7、医保 2/8.08、失业保险 0.5/0、补充公积金 2/2，格式是**个人比例 / 公司比例**）都带两个输入框，改比例或改基数，个人缴费、公司缴费、共计当场重算；下面是 **合计 / 应发（工资 − 个人缴费）/ 实发（应发 − 差距）**。默认这组数字算出来是 个人 1653.01、应发 4746.99、实发 **4714.91**，跟原始表格对得上。

排版整块重做过，为的是「一眼能读」：字段改成标签在上、数值在下（标签 11.5px 灰、数值 18px/780 等宽数字，下面垫一层 `--surface-2` 圆角片），一行四个不再挤成一串；表格 `table-layout: fixed` + 写死五列宽（项目 24% / 个人 26% / 公司 17% / 合计 17% / 说明 16%），比例那列的两个小输入框外包一层 `div` —— 之前 `td` 自己 flex 掉了，表格列会当场塌成一格，格子里的数也一并放大：正文 13.5px、项目名 14px/700、脚注三个数字 21px/800。窄屏（≤760px）自动落回三列、表格可左右滑。

**报销费用** —— 紧跟社保下面、单独一张整宽卡。表头右侧常驻合计（`¥385.50` 这种），下面是添加行：**日期（默认今天）· 内容 · 金额 · 添加**，四个宽度写死 `156 / 1fr / 120 / 74`，四格都带小标签，回车即提交。

- 列表一行一条：内容 → 金额 → **可改的日期**（行内就是 `<input type="date">`，点开改完立刻重算合计并重新排序）→ 删除
- 列表按日期倒序排，新记的这天排最上
- **删除按钮做成 30×30 的描边方块**（原来只是一个裸 ×，热区小得几乎点不到），hover 变红底红字，热区因此扩到整格
- 空的时候不是一句灰字，而是一个虚线占位块（`min-height: 124px`），卡片高度不会因为「还没记」而塌下去一半

所有改动写进 `localStorage` 的 `qingzhang.pay.v1`，秒存，刷新还在；「恢复默认」把这组数字退回上面那张表。**这份数据目前只在本机**（没接进云同步的 `state.json`），要跨设备同步说一声，我把它并进 store 一起推。

**自由排布**：10 个板块（一条四格信息带 + 7 张图 + 社保 + 报销费用）全部落进一张 12 列栅格。点顶部「排列布局」进入编辑态 —— 拖板块左上角手柄换位置，拖右下角改宽高（3–12 列 / 2–18 行），拖到视口上下边缘自动滚屏，长距离搬运也够得着。排好点「保存布局」：写进 `localStorage` 的 `qingzhang.overview.layout.v1`，同时随云同步的 `state.json` 推到私有仓库，换设备自动拿到同一份排布。「恢复默认」回初始顺序，「复制布局代码」导出 JSON 交给 R 写进 `DEFAULT_LAYOUT` 就能固化成所有人的默认版。窄屏（≤940px）不排布，按保存顺序纵向单列展示。

默认版现在带版本号 `v: 2` —— 社保和报销拆成两张卡之后坐标全变了，旧的 v1 布局继续用会把报销摁到社保原来的格子里，所以 `validLayout` 直接要求 `L.v === 2`，存过 v1 的浏览器打开即自动退回新默认版，不用手动清缓存。社保默认 `[12, 11]`、报销 `[12, 6]`，一宽一矮，都是整宽。

**消费日历的滑杆拉长三倍** —— ECharts `visualMap` 那条色带默认又矮又短，鼠标很难在上面精确定位。现在 `itemHeight` 从 130 拉到 **390**（条宽 12、`textGap` 10），长度是原来的三倍，两头极值标签也拉开了距离，拖的时候手感跟得上。

**日历** —— 按 年 / 月 / 周 / 天 四种粒度看流水。

- 月视图 6×7 栅格，整页锁一屏，不出现纵向滚动
- 格子内条目按当日笔数自动分两档：行高够（≥34px）用两块式（名称在上、金额右对齐在下），被压扁时切单行式（名称 …… 金额）；行高按格子剩余高度均分，下限 22px、上限 48px，名称与金额统一 12.5px
- 溢出部分折成 `+N 笔`：**独占格子底部一整行**，铺满右下角 ＋ 左侧的整行宽度，与 ＋ 并列；条目仍按一行 2 个排满，不再为提示让出一个条目格
- **单击格子弹「记一笔」，双击进当日明细**：单击格子任意位置（含条目、`+N 笔`）会在 **110ms** 后弹出记账浮层，日期已填成那一格 —— 判窗只比一帧长一点，落手几乎同时到。真正的双击靠两道兜底：判定窗内第二次 `pointerdown` 一落就先撤掉挂起的浮层（快双击全程不闪），万一是慢双击、浮层已经出来了，`dblclick` 里再把它收回（450ms 内只认「刚由这一格弹出」的那一个），然后 `jumpToDay` 跳「天」视图。年视图点某一天仍然是直接跳日。＋ 常驻可见，热区扩到 40px，单击也是记一笔
- **← → 翻页**：日历页按左右方向键等同于点那两颗箭头，年 / 月 / 周 / 天四种粒度各走一步（`shiftCalStep`）。弹层开着、焦点在输入框里、按着 Ctrl / ⌘ / Alt / Shift 时不抢键
- **滚轮也能翻页**：鼠标停在哪块棋盘里就在哪块里翻，不用回头去够箭头 ——
  - **月历竖向滚，一次一整月**：往下滚 → 下一月，内容自下往上推（`fx-up`），往回滚反向（`fx-down`）。整月一屏的锁没动，翻的是月份不是格子
  - **周历横向滚，整周一起走**：往下滚当「下一周」、内容从右往左推（`fx-left`），反向 `fx-right`；一到七列始终是一个整体，不会只挪半周
  - **当日明细淡入淡出**（`fx-fade`）：天页内容量一天一个样，横推竖推都会顶到边界，淡出淡入最干净 —— 试过上下推，短日子的页会露出半块空白，所以换成这个
  - 累积过 **34px** 才翻一屏（触控板轻扫不会连翻好几页），翻完锁 **430ms**；`|deltaX| > |deltaY|` 就认横向、否则认纵向，鼠标滚轮和触控板两个方向都吃得下
  - 弹层/确认框开着、日期选择器开着、鼠标在左栏表单里（`.day-side` 自己要能滚）时一律不抢滚轮
- **年历一天双色**：一天只有支出是绿、只有收入是红、两样都有就斜切一刀（`linear-gradient(155deg, 绿 0 47%, 红 53% 100%)`），深浅都按当天金额占各自峰值的比例取（`.16 → .90`）；悬停提示写成 `2026-11-08 · 支 ¥120 · 收 ¥300`，每月标题右侧也从单个数字改成两条：`−¥1,234`、`+¥5,000`，只有一边有数就只显那一边。之前「筛选为收入时年历一片空白」其实不是没渲染 —— 那 25 个收入日都在，是**颜色全绿**，绿底上根本看不出收入，改双色之后一眼就能分
- **年历的周六周日标浅粉**：`一 二 三 四 五 六 日` 里的最后两个单独换 `--weekend-ink`（亮色 `#ff8ba7` / 暗色 `#ffa1b8`），天页左栏遇到周末也套同一档高亮
- **日期摘要栏的表头重排**：原来「2026 年 11 月」在上、「周日」另外挤一行，现在是同一行 —— **左边一颗星期胶囊（周末变粉），右边年月**，下面才是大日号。先看见「几号」，再落「周几」，年份最后补，层级不打架
- **数字框的上下微调箭头全删**：`input[type=number]` 统一 `appearance: none`，`::-webkit-inner-spin-button / -outer-spin-button` 一起抹掉 —— 金额、比例、体重、报销金额一个不落。原来手一抖点到箭头金额就 ±0.01，滚轮滑过也会偷改数；现在只能打字，键盘 ↑↓ 照旧可用
- **格子内条目按分类固定排序**：餐饮 → 日常 → 交通 → 服饰 → 娱乐 → 收入，收入前面留 6px 额外间距（单行式压扁时 3px），天页明细列表是 14px。同一分类里金额大的在前
- 今天那格是纯色填充 + 荧光呼吸，不描边；年视图的今日小格直接铺主色；**周视图当天整列也铺同一档主色填充**（16% 主色 + 呼吸层），不画描边
- **无匹配记录提示改成浮层卡片**：绝对定位居中盖在棋盘上，`pointer-events: none` 不拦空白格点击，只有卡片本身可交互。实测筛选前后棋盘 `top / height` 完全不变，不再挤掉一行把周历/月历往下推
- 上方工具条：**第一行**是日期范围框（两颗 40×40 实底箭头，各带 4px 外扩热区）、粒度、搜索、收支类型与动作按钮；**筛选区**用两列栅格排成上下两行、左右边界严格对齐 —— 大项（全部 / 餐饮 / 日常 / 交通 / 服饰 / 娱乐 / 收入）在第一行左侧，**第二行只放当前分类的子类**（带每档笔数）—— **选「全部」时子项按钮全删，但那一行照旧占位**：`.fx-sub-slot` 用 `grid-row: 2`,第二行的高度、间距、边框分隔一样不落，工具条上下沿纹丝不动（实测选「全部」和选「餐饮」都是 180px，棋盘起点同一像素）。原来那排「不限 / 今天 / 近7天 / 常买 / 高于均值 / 前10笔」快捷视角已整组删除。右侧第一行两组附加筛选：金额（≤20 / 20~100 / ≥100）、星期（工作日 / 周末）。**均值与时段筛选已删除**。全部都是与「全部 / 支 / 收」同款的 `.seg-ind` 滑块，0.42s 平移且按分组换色；**任意分段控件都支持按住鼠标拖动**，指针走到哪一段就切到哪一项，拖动时滑块跟手（临时关掉过渡），松手吞掉原生 click 不回弹。`renderCatBar` 只在按钮集合真变化时重建，滑块节点保持不动，切换时是**滑动**而不是瞬间跳位。日期范围框 300px（"2026年12月13日" 完整显示），粒度段 184px
- 周视图：七列各自「日期 + 收支 → 整行一条的明细 → 底部收支占比条与净额」；日号 38px（窄屏 30px）、735 字重，跟「周X」并排贴在一起，一眼先看到是几号；条目按分类固定排序（餐饮 → 日常 → 交通 → 服饰 → 娱乐 → 收入，收入前留 6px 间距），顶对齐，空列给「无记录」提示。手机上七列横向可滚，一列仍有 130px，条目照常显示名称与金额（月格那套「同色细条」只用在月视图，不跟着收到周历上）
- 天视图**三栏并列**：左侧概览卡压缩排版 —— 大日期 / 净额 / 三项指标 / 内嵌记一笔表单 / **体重记录行（整块挪到卡片最下方）**；**表单按「支出·收入滑块 → 内容 → 分类子类 → 金额 + 保存」竖排**：收支是那颗 50px 高的 `.seg-ind` 滑块（绿↔红平移），内容独占一行，分类和子类并列一行，**最后一行是金额输入 + 「保存这笔」**，两者同高同宽铺满整行（各 36px），跟上面「内容」框一样宽；内容超一屏时整体等比缩放兜底 —— 四分类的高密度日期也**一屏完整不需要上下滑动**；中间「当日明细」按一个种类一整行分组，分组顺序同上；右侧「关于这一天」占一列、**五张卡竖向单列、高度按内容走** —— `grid-auto-rows: minmax(100px, auto)`，早先那种「等分五行」会把最后一张「还剩多少」裁掉一行字，现在每列还能自行滚动，不会被压扁 —— 副标题就是「五张小图，看今天处在什么位置」：**近 7 日支出**（折线 + 淡填充，点线都看得到数、点击跳日）、**今天花得多吗**（今天这一笔对比本月日均，倍数结论 25px、说明 11px、横条 7px，横条上那道细竖线是日均刻度，脚注写「本月 25 个消费日里第 14 多 · 最高 ¥1,050」）、**还剩多少**（一行一件事：本月剩余一行（金额 17px）+ 已用进度条 + 「已花 · 近 6 月月均」脚注，下面再一行今年结余 + 储蓄进度条；「关于这一天」一列也从 `.575fr` 放宽到 `.74fr`，字号才长得开）、**当日分类构成**（堆叠条 + 前三名图例）、**体重记录**（当天值 / 较上次 / 最近 7 次迷你线，点卡片跳到体重输入框）。删掉了近 30 天支出走势、同星期几对比、近 30 天记账热力、以及原来的「今天的位置」和单笔金额分布。全部带 hover 提示、点击跳日、入场与悬浮动效，纯内联 SVG / CSS
- 「记一笔」表单里的**分类 / 子类下拉框**统一美化：去掉原生箭头换成自绘 chevron、hover 描边、聚焦主色光圈、深色主题换浅色箭头；**展开的每个 option 也带对应分类的文字色与同色淡底**，select 本体跟着选中项换色
- **筛选小胶囊已删除**，工具条第一行只剩固定宽度控件：日期范围框 300px、粒度段 `flex: 0 0 184px`，四档切换、日期文本变长变短，粒度段横坐标都固定不动
- **「关于这一天」不再闪烁**：根因是云同步每分钟轮询无条件 `adopt → setStore → renderAll`，天页整块重建、`insIn` 入场动画反复重播。现在轮询在 `rev` 未变时只记时间不 adopt，`QZ.setStore` 对相同快照直接跳过重绘，天页再按「日期 + 数据版本 + 主题 + 当日条目」签名**复用原 DOM 节点**；三重保险下筛选、切页、轮询都不再重播动画
- **「内容」边打边认分类，还顺手切收支**：表单里那个输入框改名叫「内容」。打字时按 `guessEntry(text)` 走三步 ——
  1. **查你自己的历史**：同一个名目以前记在哪一类最多（`hintMap()` 那张 `名称 → 分类` 表），命中就直接用，连收支一起定
  2. **同义词先展开**：`expandText()` 过一遍 `NOTE_ALIAS`（「午饭 / 中饭 → 三餐」「打的 / 滴滴 → 打车」「话费 / 手机费 → 话费」……），再拿展开后的串去比
  3. **关键词最长者胜**：收入组和支出组各扫一遍，命中的关键词字节长的赢 —— 两边打平算收入（「工资」这种就该归收入）
  命中分类就把「分类」改过去、子类跟着重排；**命中的收支方向和你当前选的不一样，那颗滑块自己滑过去**（打「工资」→ 当场从「− 支出」翻到「＋ 收入」，滑块 `translateX` 走到 189.98px），手机上从格子弹出来的那颗弹层同样如此。一旦你手点过分类，这条自动线立刻停手（`modalCatManual` / `quickCatManual`），直到下次打开表单。
- **关键词表整体放宽了一档**：原来「午饭」认不进餐饮，是因为三餐那档只写了「午饭」的同义几个词、没写别的写法。现在三餐收了 早饭 / 早点 / 午饭 / 中饭 / 晚饭 / 夜饭 / 宵夜 / 盒饭 / 便当 / 食堂 / 米线 / 麻辣烫 / 汉堡 / 披萨 / 寿司……；饮料补了 矿泉水 / 拿铁 / 雪碧 / 红牛；水果补了 榴莲 / 芒果 / 樱桃；超市补了 酱油 / 醋 / 食盐 / 大米；酒店补了 民宿 / 宾馆 / 住宿；家居百货补了 牙膏 / 牙刷 / 垃圾袋 / 拖把 / 灯泡 / 插座；交通新开「打车」这档；服饰补了 羽绒服 / 毛衣 / 牛仔；学习补了 课本 / 试卷 / 打印 / 文具 / 学费 / 培训；收入那边 工资 收了 薪资 / 薪水 / 月薪 / 发薪 / 薪酬 / 劳务，津贴 收了 饭补 / 餐补 / 车补 / 房补 / 补助，绩效 收了 提成 / 分红 / 奖励 / 全勤 / 季度奖 / 十三薪，其它 收了 报销 / 利息 / 返现 / 中奖 / 转入 / 收到。判定是「最长命中」而不是「先到先得」，所以「打车去吃饭」这种串不会乱跳
- **两套记账布局，一套字段、一套落库逻辑**：同一份 DOM，靠 `.entry-grid` 的 `grid-template-areas` 换排法，字段本身一个不多一个不少 ——
  - **侧栏「记一笔」**：`"note note" / "cat sub" / "date amount"` —— 滑块、内容、分类子类、**日期 + 金额同一行**
  - **从月历 / 周历格子弹出来的那颗**：`"note note" / "cat sub" / "amount amount"` —— 滑块、内容、分类子类、**金额独占一行铺满**；日期不占格子，改成弹层标题右侧一颗日期胶囊（`2026 年 11 月 8 日 · 周日`），日期就是那一格，没什么可改的
  - 整颗再放大一档（520px 宽、输入框 46px、金额 54px），开头焦点直接落在「内容」上，打完内容分类基本已经认好，回车保存
  - 手机上（≤620px）两个都落成四行：`"note note" / "cat sub" / "date date"` 或 `"amount amount"` —— 390px 宽度下日期和金额挤一行会截成 `2026-11-…`，所以宁可多占一行也要显示全
- **体重记录**：天页左栏按日期记一条体重（20–300 kg，可删除），写进 `state.store.weights`，随 localStorage 与云同步 `state.json` 一起走；私有仓库和自建后端的快照、校验都已加这个字段。总览里自动生成折线图
  - **种子数据来自原始 xlsx**：每个月表的第 4 行就是「体重」，一格一天，`data.js` 的 `weights` 对象里存 `{日期: kg}`，现已覆盖 2022-08-29 → 2026-10-25 共 **569 条**（2025、2026 两份账单已整表同步）。`mergeSeedWeights()` 每次载入只补「本地还没有、且没被主动删掉」的日期，你自己的记录永远压在上面，云同步回来的快照也冲不掉种子值
  - 折线走**时间轴**：跨度四年多，标签写成 `26.07` 这种「年.月」，比 MM-DD 分得清；两笔之间隔了 45 天以上就插一个空点**把线断开**（2023-11-19 → 2024-08-01 那段 256 天的空档不再被画成一条缓慢下滑的假曲线）
- **月度收支趋势不再吞滚轮**：撤掉了图表上的 `dataZoom inside`（它会 `preventDefault` wheel），鼠标停在图上时整页照常滚动
- **日期数字改成浅色放大嵌入效果**：月历日号、周历日号、天页大日期统一加浅底圆角片 + `inset` 内阴影，尺寸放大一档；今日仍是实心主色不描边。窄屏自动收回小尺寸
- **矮窗口弹窗不再裁底**：`max-height: 780px` 以下（手机横屏、分屏）弹层改成顶部对齐并整层可滚，保存按钮永远够得着；弹窗入场动画从 0.42s 收到 0.26s
- **日期标题弹层随粒度切换**：点最上方日期框，年视图弹年历（12 个年份）、月视图弹月历（12 个月，左右翻年）、周视图弹周历（当月各周及日期区间，左右翻月）、天视图弹日历（周一开头的迷你月历，左右翻月）。选中即跳到对应年 / 月 / 周 / 日
- **全局悬浮提示**：接管原生 `title` 与动态图表的 `data-tip`，气泡固定在鼠标上方 14px、`pointer-events: none`，不会被光标遮挡；动态渲染的按钮和图表元素都能吃到

**明细** —— 全量流水表格，按年 / 月 / 分类 / 关键字筛选，可增删改。

## 数据

`assets/data.js` 是一个 `window.BILL_DATA` 赋值，记录由三份 xlsx 逐日明细抽取而来：

| 来源 | 期间 | 笔数 |
|---|---|---|
| 2024后账单.xlsx | 2024-07-22 → 2024-12-31 | 553 |
| 2025账单.xlsx | 2025 全年 | — |
| 2026账单.xlsx | 2026 全年 | — |

单条记录结构：

```js
{
  id: 'a2024-0001',
  date: '2024-07-22', year: 2024, month: 7,
  type: 'expense',          // expense | income
  category: '餐饮',         // 餐饮 日常 交通 服饰 娱乐 收入
  raw: '餐饮/零食',          // 源表里的原始分类，保留以便回溯
  note: '午饭',
  amount: 23.5
}
```

源表的宽表格式已摊平：每两天一列（名称 + 金额）、行是分类，转成一条一条的流水。`共计` / `攒` / `每日统计` / `体重` 这类汇总行跳过，金额为 0 的格子丢弃；其中「体重」行单独抓出来喂给 `weights`。

子类的展示顺序由 `SUB_ORDER` 定死，不跟随数据出现顺序 —— 日常：房租 / 水电费 / 家居百货 / 酒店 / 电子产品 / 其它；娱乐：**魔方** / 比赛 / 电子产品 / 订阅服务 / 话费 / 人情往来 / 学习 / 其它。筛选胶囊和「记一笔」的子类下拉都按这个顺序排；记账时**内容**（原「备注」）命中某档的关键词（魔方、魔表、五阶、天马……）会自动建议归到那一档。

运行时新增的记账保存在 `localStorage`（键 `qingzhang.ledger.v1`），与种子数据合并展示，互不覆盖。

## 云同步

不接后端时，数据只在本机浏览器的 localStorage 里 —— 换设备、清缓存就没了。面板里两种后端可选：

### GitHub 私有仓库（零服务器，推荐）

数据存进一个**私有**仓库里的 `state.json`（默认 `LeanSun/bill-data`），走 GitHub Contents API。每次保存就是一个 commit —— **git 历史就是全套备份**，随时能翻回任何一版。

1. 建（或确认有）私有仓库，如 `LeanSun/bill-data`
2. GitHub → Settings → Developer settings → **Fine-grained tokens** → Generate new token
3. Repository access 选 **Only select repositories** → 勾这个私有仓库
4. Permissions → Repository permissions → **Contents: Read and write**（在搜索框输入 contents 可以直接筛出来）
5. 生成后把 `github_pat_…` 粘进面板的「访问令牌」

注意两点：仓库必须是**私有**的，面板会拒绝连公开仓库；令牌只存本机浏览器的 localStorage，权限也只有这一个仓库，泄露了影响面有限，但还是别贴给别人。

### 自建服务器

接上 `server/` 之后多设备共用一份账。侧栏左下「云同步」→ 切到「自建服务器」→ 填地址与口令。

首次连接时如果云端已有数据，会给两个选项：用云端版本覆盖本地，或用本地覆盖云端。**不做隐式合并** —— 两边都改过时让你自己选，比悄悄合丢一条强。

接上之后：本地记一笔 → 1.2 秒防抖后自动推送；切回标签页、每分钟轮询各拉一次。冲突检测：服务器模式靠 `rev` 版本号，GitHub 模式靠文件 sha —— 基线对不上而你本地又有未推送改动，就会浮出二选一。

同一面板里还有「导出备份 / 导入备份」（整份 JSON）—— 换域名、换设备、防手滑都用它。GitHub 模式下导入替换后的旧版仍留在 git 历史里。

后端接口、部署方式（VPS + Caddy / Docker / 平台）见 [`server/README.md`](server/README.md)。

> 后端是单用户单口令的私人账本，不是多租户服务。放公网前务必配 HTTPS，并把 `ALLOWED_ORIGINS` 收敛到具体来源。

## 实现上的几处取舍

**主题切换不吃帧。** 早期版本用 View Transitions 的 `clip-path` 圆形扩散 —— 半径变化不是合成动画，每帧都要重新裁剪两张整页快照再光栅化，60fps 给不出来。现在改成单帧换色 + 一颗独立合成层的光斑（只动 `transform` / `opacity`），大面积元素的 `background-color` 过渡全部移除，侧边栏的 `backdrop-filter` 也去掉了。

**日历一屏。** `#view-calendar` 锁 `calc(100dvh - var(--topbar-h))`，`.cal-grid` 用 `grid-template-rows: repeat(6, minmax(0, 1fr))`。默认的 `1fr` 最小值是 `auto`，内容一多就撑破容器；改成 `minmax(0, 1fr)` 才真正等分。

**条目高度不写死。** 渲染两遍：先把条目全部写进格子，再量真实可用高度，按条数与列数均分出行高，条少时每条最高 46px，条多时压到 15px 为止。行高跨过 34px 自动从两块式换成单行式。

**同比口径。** 2024 只有下半年。拿全年比半年会算出 +160% 的假增速，所以任一边不足 12 个月就换成月均比，标签也写「月均」。

## 本地运行

静态页面，双击 `index.html` 就行。要起服务：

```bash
python -m http.server 8080
# 或
npx serve .
```

然后开 `http://localhost:8080`。

要连后端（一个进程同时提供站点和 API）：

```bash
node server/server.js
```

首次启动打印一串随机口令。开 `http://127.0.0.1:8787`，左下「云同步」填 `http://127.0.0.1:8787` 和那串口令。

### 本机部署（Windows）

不动命令行的话，两个脚本就够：

| 脚本 | 作用 |
|---|---|
| `start-ledger.cmd` | 双击启动。带日志窗口，关窗口即停；可改端口、口令、跨域来源 |
| `autostart.cmd` | 双击一次，写入开机自启（`shell:startup` 快捷方式，最小化窗口）；加参数 `uninstall` 撤销 |

数据落在 `server\data\`：`password.txt`（口令）、`secret.key`（令牌密钥）、`state.json`（账本增量层）、`backups\`（最近 20 份历史）。整个目录照常被 `.gitignore` 挡在仓库外，但**记得自己备份** —— 换电脑或重装系统时它才是你的全部线上改动。

手机 / 平板在同一 Wi-Fi 下访问 `http://本机IP:8787`（启动日志会列出）。第一次绑 0.0.0.0 时 Windows 防火墙可能弹窗，允许「专用网络」即可。
