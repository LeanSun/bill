# 轻账 · 收支看板

个人账单可视化面板。2024 — 2026 三年、1959 笔流水，全部跑在一个静态页里 —— 无构建、无依赖服务、无后端。

打开 `index.html` 即可用。

---

## 界面

四个视图，侧栏切换。

**总览** —— 顶部一条四格信息带（收入 / 支出 / 结余 / 储蓄率，各带同比、月均日均、笔数与 12 个月走势线），下面是速览带（本月支出 / 本月结余 / 日均支出 / 单笔均值）和分类构成、月度趋势图。

**日历** —— 按 年 / 月 / 周 / 天 四种粒度看流水。

- 月视图 6×7 栅格，整页锁一屏，不出现纵向滚动
- 格子内条目按当日笔数自动分两档：≤4 笔用两块式（名称在上、金额右对齐在下），>4 笔切单行式（名称 …… 金额），行高按格子剩余高度均分
- 溢出部分折成 `+N 笔`，点格子或点它展开当日全部明细浮层
- 今天那格是荧光呼吸描边，4.6 秒一个来回
- 上方工具条压成一行：月导航 · 粒度 · 分类与子类 · 搜索 · 收支筛选 · 重置

**分析** —— 年度卡片（收入 / 支出 / 储蓄率 / 月均），逐年对比柱状图，分类构成饼图。任一边不足 12 个月时同比自动换算成月均比，避免半年比全年算出假增速。

**明细** —— 全量流水表格，按年 / 月 / 分类 / 关键字筛选，可增删改。

## 数据

`assets/data.js` 是一个 `window.BILL_DATA` 赋值，记录由三份 xlsx 逐日明细抽取而来：

| 来源 | 期间 | 笔数 |
|---|---|---|
| 2024后账单.xlsx | 2024-07-22 → 2024-12-31 | 553 |
| 2025账单.xlsx | 2025 全年 | — |
| 2026账单.xlsx | 2026 全年 | — |

单条记录结构：

```js
{
  id: 'a2024-0001',
  date: '2024-07-22', year: 2024, month: 7,
  type: 'expense',          // expense | income
  category: '餐饮',         // 餐饮 日常 交通 服饰 娱乐 收入
  raw: '餐饮/零食',          // 源表里的原始分类，保留以便回溯
  note: '午饭',
  amount: 23.5
}
```

源表的宽表格式已摊平：每两天一列（名称 + 金额）、行是分类，转成一条一条的流水。`共计` / `攒` / `每日统计` / `体重` 这类汇总行跳过，金额为 0 的格子丢弃。

运行时新增的记账保存在 `localStorage`（键 `qingzhang.ledger.v1`），与种子数据合并展示，互不覆盖。

## 结构

```
index.html              单页骨架，四个 view 与全部浮层
assets/
  styles.css            设计令牌、布局、日历栅格、动画、响应式梯度
  app.js                状态、渲染、图表、筛选、记账、主题
  data.js               种子数据（window.BILL_DATA）
  echarts.min.js        图表库（本地引入，无 CDN 依赖）
```

## 实现上的几处取舍

**主题切换不吃帧。** 早期版本用 View Transitions 的 `clip-path` 圆形扩散 —— 半径变化不是合成动画，每帧都要重新裁剪两张整页快照再光栅化，60fps 给不出来。现在改成单帧换色 + 一颗独立合成层的光斑（只动 `transform` / `opacity`），大面积元素的 `background-color` 过渡全部移除，侧边栏的 `backdrop-filter` 也去掉了。

**日历一屏。** `#view-calendar` 锁 `calc(100dvh - var(--topbar-h))`，`.cal-grid` 用 `grid-template-rows: repeat(6, minmax(0, 1fr))`。默认的 `1fr` 最小值是 `auto`，内容一多就撑破容器；改成 `minmax(0, 1fr)` 才真正等分。

**条目高度不写死。** 渲染两遍：先把条目全部写进格子，再量真实可用高度，按条数与列数均分出行高，条少时每条最高 46px，条多时压到 15px 为止。行高跨过 34px 自动从两块式换成单行式。

**同比口径。** 2024 只有下半年。拿全年比半年会算出 +160% 的假增速，所以任一边不足 12 个月就换成月均比，标签也写「月均」。

## 本地运行

静态页面，双击 `index.html` 就行。要起服务：

```bash
python -m http.server 8080
# 或
npx serve .
```

然后开 `http://localhost:8080`。
