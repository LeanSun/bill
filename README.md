# 轻账 · 收支看板

个人账单可视化面板。2024 — 2026 三年、1959 笔流水，全部跑在一个静态页里 —— 无构建、无依赖、无数据库。

打开 `index.html` 即可用。要跨设备共用一份账，附带一个零依赖的 Node 后端（`server/`），单进程同时发站点和 API。

线上：<https://leansun.github.io/bill/>

---

## 界面

两个视图，侧栏切换：**总览（含年度分析）** 与 **日历**，**打开默认落在日历**（无 hash 时自动补 `#/calendar`）。旧的 `#/analysis`、`#/stats`、`#/trend` 深链仍可用，会落到合并后的总览页。侧栏里还放着「记一笔」「深浅切换」和左下角的「云同步」；窄屏（≤940px）侧栏折成横条，云同步改由同排的云图标进入，桌面端不显示这个图标。

页面顶部不再有标题行：正文从 18px 留白起排，日历因此能多吃约 70px 的高度。侧栏宽 208px，右侧内容区按视口自适应铺满。

**总览** —— 顶部一条四格信息带（收入 / 支出 / 结余 / 储蓄率，各带同比、月均日均、笔数与 12 个月走势线），下面是速览带（本月支出 / 本月结余 / 日均支出 / 单笔均值）和分类构成、月度趋势图；再往下的「年度分析与对比」把原来的分析页整块接了进来（年度卡片、逐年对比、分类构成、高频项目等九张图）。切换视图时十张图一起重绘。

**日历** —— 按 年 / 月 / 周 / 天 四种粒度看流水。

- 月视图 6×7 栅格，整页锁一屏，不出现纵向滚动
- 格子内条目按当日笔数自动分两档：行高够（≥34px）用两块式（名称在上、金额右对齐在下），被压扁时切单行式（名称 …… 金额）；行高按格子剩余高度均分，下限 22px、上限 48px，名称与金额统一 12.5px
- 溢出部分折成 `+N 笔`
- **点格子任意位置（含条目、`+N 笔`）都切到「天」视图**，和年历里点某一天完全同一条逻辑（`jumpToDay`）；不再弹浮层。只有点格子**右下角的 ＋** 才弹「记一笔」表单。＋ 常驻可见，热区扩到 40px
- 今天那格是纯色填充 + 荧光呼吸，不描边；年视图的今日小格直接铺主色
- 上方工具条改成**双行**：第一行是日期范围框（两颗 40×40 实底箭头，各带 4px 外扩热区）、粒度、搜索、收支类型与动作按钮，全部放大；第二行是筛选区 —— 主类 7 等分的分段控件与「全部 / 支 / 收」完全同款（等宽列 + `.seg-ind` 滑块，按当前分类色填充），选中分类后右侧再并排出现子类分段控件，**所有按钮常驻可见，不再有隐藏项**
- 周视图：七列各自「日期 + 收支 → 整行一条的明细 → 底部收支占比条与净额」；条目按分类聚拢、同类相邻，顶对齐，空列给「无记录」提示
- 天视图：左侧 300px 概览卡（大日期 / 净额 / 三项指标 / 支出构成 / **内嵌记一笔表单**，不弹窗，支出绿 / 收入红有底色区分）；右侧「当日明细」按**一个种类一整行**分组，行内每笔是和月/周同款的两块式大胶囊（最小 132×46px）；下方「关于这一天」六张图贴底对齐、卡内正文统一贴底 —— 近 30 天走势（30 个可点数据点）、近 7 日柱状、最大一笔占比环、近 30 天记账热力（30 格）、同星期几对比（5 根柱）、本月累计与月末预计（进度条）。全部带 hover 提示、点击跳到对应那天、入场与悬浮动效，纯内联 SVG / CSS，不依赖 ECharts 尺寸
- **全局悬浮提示**：接管原生 `title` 与动态图表的 `data-tip`，气泡固定在鼠标上方 14px、`pointer-events: none`，不会被光标遮挡；动态渲染的按钮和图表元素都能吃到

**明细** —— 全量流水表格，按年 / 月 / 分类 / 关键字筛选，可增删改。

## 数据

`assets/data.js` 是一个 `window.BILL_DATA` 赋值，记录由三份 xlsx 逐日明细抽取而来：

| 来源 | 期间 | 笔数 |
|---|---|---|
| 2024后账单.xlsx | 2024-07-22 → 2024-12-31 | 553 |
| 2025账单.xlsx | 2025 全年 | — |
| 2026账单.xlsx | 2026 全年 | — |

单条记录结构：

```js
{
  id: 'a2024-0001',
  date: '2024-07-22', year: 2024, month: 7,
  type: 'expense',          // expense | income
  category: '餐饮',         // 餐饮 日常 交通 服饰 娱乐 收入
  raw: '餐饮/零食',          // 源表里的原始分类，保留以便回溯
  note: '午饭',
  amount: 23.5
}
```

源表的宽表格式已摊平：每两天一列（名称 + 金额）、行是分类，转成一条一条的流水。`共计` / `攒` / `每日统计` / `体重` 这类汇总行跳过，金额为 0 的格子丢弃。

运行时新增的记账保存在 `localStorage`（键 `qingzhang.ledger.v1`），与种子数据合并展示，互不覆盖。

## 云同步

不接后端时，数据只在本机浏览器的 localStorage 里 —— 换设备、清缓存就没了。面板里两种后端可选：

### GitHub 私有仓库（零服务器，推荐）

数据存进一个**私有**仓库里的 `state.json`（默认 `LeanSun/bill-data`），走 GitHub Contents API。每次保存就是一个 commit —— **git 历史就是全套备份**，随时能翻回任何一版。

1. 建（或确认有）私有仓库，如 `LeanSun/bill-data`
2. GitHub → Settings → Developer settings → **Fine-grained tokens** → Generate new token
3. Repository access 选 **Only select repositories** → 勾这个私有仓库
4. Permissions → Repository permissions → **Contents: Read and write**（在搜索框输入 contents 可以直接筛出来）
5. 生成后把 `github_pat_…` 粘进面板的「访问令牌」

注意两点：仓库必须是**私有**的，面板会拒绝连公开仓库；令牌只存本机浏览器的 localStorage，权限也只有这一个仓库，泄露了影响面有限，但还是别贴给别人。

### 自建服务器

接上 `server/` 之后多设备共用一份账。侧栏左下「云同步」→ 切到「自建服务器」→ 填地址与口令。

首次连接时如果云端已有数据，会给两个选项：用云端版本覆盖本地，或用本地覆盖云端。**不做隐式合并** —— 两边都改过时让你自己选，比悄悄合丢一条强。

接上之后：本地记一笔 → 1.2 秒防抖后自动推送；切回标签页、每分钟轮询各拉一次。冲突检测：服务器模式靠 `rev` 版本号，GitHub 模式靠文件 sha —— 基线对不上而你本地又有未推送改动，就会浮出二选一。

同一面板里还有「导出备份 / 导入备份」（整份 JSON）—— 换域名、换设备、防手滑都用它。GitHub 模式下导入替换后的旧版仍留在 git 历史里。

后端接口、部署方式（VPS + Caddy / Docker / 平台）见 [`server/README.md`](server/README.md)。

> 后端是单用户单口令的私人账本，不是多租户服务。放公网前务必配 HTTPS，并把 `ALLOWED_ORIGINS` 收敛到具体来源。

## 实现上的几处取舍

**主题切换不吃帧。** 早期版本用 View Transitions 的 `clip-path` 圆形扩散 —— 半径变化不是合成动画，每帧都要重新裁剪两张整页快照再光栅化，60fps 给不出来。现在改成单帧换色 + 一颗独立合成层的光斑（只动 `transform` / `opacity`），大面积元素的 `background-color` 过渡全部移除，侧边栏的 `backdrop-filter` 也去掉了。

**日历一屏。** `#view-calendar` 锁 `calc(100dvh - var(--topbar-h))`，`.cal-grid` 用 `grid-template-rows: repeat(6, minmax(0, 1fr))`。默认的 `1fr` 最小值是 `auto`，内容一多就撑破容器；改成 `minmax(0, 1fr)` 才真正等分。

**条目高度不写死。** 渲染两遍：先把条目全部写进格子，再量真实可用高度，按条数与列数均分出行高，条少时每条最高 46px，条多时压到 15px 为止。行高跨过 34px 自动从两块式换成单行式。

**同比口径。** 2024 只有下半年。拿全年比半年会算出 +160% 的假增速，所以任一边不足 12 个月就换成月均比，标签也写「月均」。

## 本地运行

静态页面，双击 `index.html` 就行。要起服务：

```bash
python -m http.server 8080
# 或
npx serve .
```

然后开 `http://localhost:8080`。

要连后端（一个进程同时提供站点和 API）：

```bash
node server/server.js
```

首次启动打印一串随机口令。开 `http://127.0.0.1:8787`，左下「云同步」填 `http://127.0.0.1:8787` 和那串口令。

### 本机部署（Windows）

不动命令行的话，两个脚本就够：

| 脚本 | 作用 |
|---|---|
| `start-ledger.cmd` | 双击启动。带日志窗口，关窗口即停；可改端口、口令、跨域来源 |
| `autostart.cmd` | 双击一次，写入开机自启（`shell:startup` 快捷方式，最小化窗口）；加参数 `uninstall` 撤销 |

数据落在 `server\data\`：`password.txt`（口令）、`secret.key`（令牌密钥）、`state.json`（账本增量层）、`backups\`（最近 20 份历史）。整个目录照常被 `.gitignore` 挡在仓库外，但**记得自己备份** —— 换电脑或重装系统时它才是你的全部线上改动。

手机 / 平板在同一 Wi-Fi 下访问 `http://本机IP:8787`（启动日志会列出）。第一次绑 0.0.0.0 时 Windows 防火墙可能弹窗，允许「专用网络」即可。
